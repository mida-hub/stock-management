# バックテスト検証ログ（採用・不採用ルール記録）

同じ仮説を何度も検証しないよう、バックテストで試した改善案の結果を記録します。

## 2026-11-22: Model C（堅実ディフェンシブ）の25MA反発・DC撤退検証 → **不採用**
- **検証対象**: 日本株103銘柄 / 過去365日 / コスト0.2%控除
- **Baseline（従来）**: `25MA乖離 -4%〜+3%`、`損切り -5% / 利確 +10%`
  - **結果**: `381回`, 勝率 `47.8%`, 平均 `+1.64%`, **PF `1.57`**
- **不採用①（Entryのみ `25MA >= 0%` に変更）**:
  - **結果**: `321回`, 勝率 `45.2%`, 平均 `+1.25%`, PF `1.42`
  - **理由**: 25MA上抜けまで待つと買い値が高くなり、期待値が低下した。
- **不採用②（Exitのみ `25MA < 75MA` デッドクロス即撤退を追加）**:
  - **結果**: `642回`, 勝率 `45.5%`, 平均 `+0.82%`, PF `1.55`
  - **理由**: 一時的な押し目調整で早すぎる撤退が増え、1回あたりの平均利益が半減した。
