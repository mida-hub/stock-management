# 投資・トレードの基本哲学（引き算と資金管理）

指標やルールを増やしすぎて判断軸がブレるのを防ぐため、本リポジトリにおける意思決定の軸を以下に定める。

---

## 1. テクニカル・ファンダメンタルズは「引き算」に使う
* **多くの指標を組み合わせない**: テクニカル指標は遅行指標であり、増やすほどサインの矛盾や確証バイアス（自分の買いたい理由探し）を招く。
* **役割を2つに限定する**:
  1. **全体相場の把握**: 日本株・米国株全体の地合い（25日SMA上回り比率・RSI中央値など）を見て、「攻める日か、守る／休む日か」を決める。
  2. **地雷銘柄の除外（ネガティブ・スクリーニング）**: 決算直前（`⚠️`）、業績急悪化、ガバナンス懸念、値嵩株など、明らかにリスクの高い銘柄を最初から土俵に上げない。

## 2. 勝敗を決めるのは「資金管理」
* **現物買いのみ（信用売りは採用しない）**: 下落局面であっても、信用売り（空売り）は踏み上げリスクや損失無限大リスクがあり現物買いの数倍難しいため、本戦略では採用しない。下落局面では「キャッシュ比率を高めて休む」ことで対応する。
* **スイング枠と長期枠の混同禁止（塩漬け防止）**: スイングトレードとしてエントリーした銘柄が下落した際、「長期投資に切り替えよう」と都合よく時間軸をずらして塩漬けにしない（過去の `SNOW` 4年4ヶ月拘束 `-34.86%` の教訓）。時間軸の切り替えは厳禁とし、当初の逆指値で撤退する。
* **入り口はシンプルに、管理は厳格に**: 200日SMA上・25日SMA付近の押し目というシンプルな定規で候補を絞ったら、あとは資金管理を徹底する。
* **許容損失の固定**: 1ポジションあたりの最大損失を `-6%` 以内（または `2×ATR`）に固定し、エントリー前に逆指値ラインを決める。
* **リスクリワード比**: 損失幅に対して `1 : 2` 以上の利幅が見込める局面のみエントリーする。
* **地合いに応じたサイズ調整**: 地合いが悪い時は無理にフルポジションを持たず、打診買いや見送り（キャッシュ比率引き上げ）でドローダウンを防ぐ。

## 3. メンタル・連敗時の対処ルール（ドローダウン管理）
* **損切りは「負け」ではなく「必要経費（保険料）」**: トレードは確率のゲームであり、1回ごとの勝ち負けにこだわらない（学校・仕事の「毎回100点」思考を捨てる）。-6%の損切りは大きな利益を取りに行くための必要経費であり、これを渋ると塩漬け・退場につながる。
* **連敗は確率通り起きる**: 勝率50%前後の優れたモデルでも3〜5連敗は統計上自然に発生する。連敗＝手法の崩壊ではないと割り切る。
* **含み損を抱えた状態で判断しない**: 人間の脳（損失回避性）は損切りに向いていないため、エントリーと同時に逆指値を入れて機械に任せる。
* **3連敗時のブレーキ**: 連続で損切りが続いた時は、① まず地合いを確認して悪ければ休む（新規エントリー停止）、② 次のトレードは投入資金を半分に落とす（クーリングオフ）、③ 「1回で取り返そう」とロットを上げない。
* **エージェントによる段階的引き止めルール（注意・忠告・警告）**: 保有銘柄が損切りラインに接近・到達したにもかかわらずユーザーが躊躇している場合、エージェントは以下の3段階でルールの徹底を呼びかけ、感情的なお祈り・ナンピンを引き止めること：
  1. **注意**: 損切りライン接近〜到達時に、エントリー時の根拠と「人間の損失回避バイアスが働きやすい場面である」ことを冷静にリマインドする。
  2. **忠告**: それでも躊躇・先送りする場合は、当初の `-6%` ルールと放置時の損失拡大リスクを具体的な金額・%で示して再考を促す。
  3. **警告**: 損切り撤回やナンピンをしようとする場合は、「退場プロファイルへの接近（明確なルール違反）」として強く引き止める。

## 4. モデルの定期点検ルール（レジーム変化の検知）
* **月1回の健康診断**: 毎日ルールをいじると過剰適合になるため、月1回程度 `stock-management backtest --days 90` を実行し、過去365日の基準値（PF・勝率）と比較する。
* **劣化サインの切り分け**: 直近90日のPFが `1.0` を下回った場合は、`--regime-min-pct 50` を付けて再検証する。「地合いが悪いだけ」なら地合い回復まで休み、「地合いが良くてもPF < 1.0」ならモデルの見直しを行う。
