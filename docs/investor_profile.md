# 投資家プロファイル（強みと弱点の整理）

過去のトレード履歴（`trade_america_2021_2026.csv`）および対話から導き出した自己プロファイル。エージェントは損切りラインの「注意・忠告・警告」を行う際、以下の傾向を根拠として参照すること。

---

## 1. 強み（武器になる資質）
* **高いメタ認知と自己修正力**: 失敗や迷いを感情論で終わらせず、ルール・ツール・チェック機構に落とし込んで再発防止できる。
* **「引き算」と規律の合理性**: 現物買いのみ・許容損失 `-6%`・R/R `1:2` 以上というシンプルな基準で戦える。
* **選球眼**: 200日SMA上・増収増益・高配当など、素直で崩れにくい優良株を選ぶ目利きがある。

## 2. 弱点（陥りやすい罠・引き止め時の根拠）
1. **「時間軸のすり替え」による塩漬けバイアス**:
   * 優秀な銘柄を選べるからこそ、下落時に「良い会社だから長期保有に切り替えよう」とスイング枠を長期枠にすり替えて損切りを先送りしやすい（過去の `SNOW` 4年4ヶ月拘束 `-34.86%`）。
2. **含み損時の「損失回避性（お祈り・躊躇）」**:
   * 事前の分析が冷静で納得感を持って入る分、いざ損切りラインに近づくと「自分の分析は正しかったはず」「もう少し待てば戻るかも」と躊躇しやすい。
3. **「完璧な根拠」を求めすぎる分析麻痺**:
   * 納得感を重視しすぎてエントリーの好機を逃したり、逆に「綺麗なチャート」に惚れ込んでリスク管理が甘くなる場面がある。

## 3. 弱点を補うための3つの行動指針
* **エントリーと同時に逆指値をセットする**（含み損を抱えた脳に判断させない）。
* **エントリー時点で時間軸（スイング／長期）を固定し、絶対に越境させない**。
* **`--health-check` と地合い指標（25MA上回り比率 50%未満）をトリガーに、機械的に休む**。
